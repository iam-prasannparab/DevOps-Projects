# Terraform

**Status:** Not implemented in the supplied pipeline. This directory is reserved for AWS infrastructure (VPC, subnets, EKS, IAM) if you choose to provision it as code.

When added, use `terraform init`, `terraform plan`, and `terraform apply`. Destroy with `terraform destroy` when finished. EKS, EC2, NAT gateways, and load balancers all incur ongoing AWS charges.
